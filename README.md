# Smartcardio


SmartCardio is a full-stack web application currently under development.  
It focuses on patient management and provides CRUD functionalities as a foundation for future cardiovascular disease analysis features.

## Current Features
- Patient CRUD (Create, Read, Update, Delete)
- Patient list and details pages
- Additional informational pages
- REST API with Spring Boot
- MySQL database integration

## Tech Stack
- Frontend: Angular
- Backend: Spring Boot
- Database: MySQL
- Tools: Maven, Git, GitHub

## Project Status
🚧 This project is still under development.  
More features related to cardiovascular risk analysis and statistics will be added.
